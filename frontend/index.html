Safe handling rules

  • Never visit, ping or scan an indicator
  • Never run a file because of its hash
  • Use isolated analysis environments
  • High risk ≠ confirmed compromise
  • Correlation ≠ attribution
  • Record who validated what, and when

Mapping policy

  • Mapping is conservative: only when confidence ≥ 50
  • An indicator alone never proves a technique
  • Unmapped records show “insufficient evidence”
  • Malware indicators that are domains/IPs map to Command and Control
  • Verify IDs against attack.mitre.org before publishing

ATT&CK describes adversary behaviour for defenders; it is used here only to organise detection and awareness work.

Phishing red flags

  • Urgent or threatening language
  • Sender domain slightly different from the real one
  • Link text differs from the real destination
  • Unexpected attachment or QR code
  • Request for passwords, MFA codes or gift cards
  • Payment-detail changes by email only
  • Generic greeting, odd grammar or tone
